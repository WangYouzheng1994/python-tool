# 项目协作规则

1. 本规则只适用于 `ticket_ocr/`；使用简体中文沟通，标识符、命令和报错保持原文。
2. 开始任务先读[交接](.agents/memory/handoff.md)、[需求](docs/requirements.md)、[决策](.agents/memory/decisions.md)和[开发规范](docs/PYTHON_DEVELOPMENT_STANDARDS.md)，需要背景时读[项目记忆](.agents/memory/project.md)。
3. 按[开发工作流](.agents/workflows/development.md)推进；文档写具体做法，使用简短编号，不重复规则正文。
4. 不将候选技术写成已确认选型；先完成基础文档，再与用户选择 Python 版本和类库。
5. 只改当前任务涉及的文件，不顺带重构其他项目，不覆盖用户未提交的改动。
6. 重大方案先确认；安装依赖、下载模型及新增外部服务前说明目的和影响，依照当前授权执行。
7. 验证以实际执行结果为准，明确未执行、失败及阻塞项，不把文档约定说成已经实现的能力。
8. 任务结束更新交接；稳定偏好写入项目记忆，已确认决策写入决策记录，需求变更写入需求文档，其他文件用链接引用。
9. 不向文档、记忆或提交写入凭据、客户票据及敏感识别内容。
10. `.agents/` 是文档目录，不会自行执行流程或更新记忆；不以文档代替真实的工具配置和检查。
