# 协作文档目录

1. 从 [AGENTS.md](../AGENTS.md) 进入，按其中的阅读顺序了解当前上下文。
2. [开发工作流](workflows/development.md)说明每次任务怎么推进，不是自动执行脚本或已注册的代理。
3. [项目记忆](memory/project.md)保存稳定背景与偏好，不复制需求和代码结构。
4. [决策记录](memory/decisions.md)保存已确认选择、理由及待选型事项，不把建议当结论。
5. [交接记录](memory/handoff.md)只保留最新进度、检查结果和下一步，不堆积会话全文。
6. 这些文件由协作者显式读取和更新；`.agents/` 不会被所有工具自动加载，也不会自动产生持久记忆。
7. 在本项目目录使用 Claude 时，由 `CLAUDE.md` 引用共享规则；其他工具应显式读取 `AGENTS.md`，是否自动加载以其实际能力为准。
