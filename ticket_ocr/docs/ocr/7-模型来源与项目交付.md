## 15. 模型从哪里来与如何选

### 15.1 把来源链的角色拆开

| 角色 | 负责什么 | 不能仅凭什么认定 |
| --- | --- | --- |
| 算法/训练方案作者 | 网络、loss、训练工具或方法 | 托管账号名字不一定证明具体文件作者 |
| 训练方 | 实际准备数据并训练参数 | `.onnx` 后缀或 PP 文件名不能证明 |
| 转换/适配方 | 导出、算子转换、字典和 SDK 适配 | 转换不等于重新训练 |
| 发布方 | 打包并发布模型文件与说明 | 发布方可能不是原训练方 |
| 平台 | 托管、检索和下载 | ModelScope/Hugging Face/GitHub 不是训练来源证明 |

1. 优先从官方作者、正式发布和可追溯适配项目开始，核对模型卡、版本、文件 hash、许可证、训练与转换说明、适用任务及评测范围。
2. 下载位置在某国家/地区，不代表训练方或算法来源就在该地区；网络可访问性是交付条件，不是准确率和可信度证据。
3. 原始模型、转换模型、适配配置和代码可能各有许可证，不能只看仓库顶层许可证；商用与再分发前应完成相应审查。
4. 哈希校验提供一致性，来源信任还需要官方发布、受控渠道和追溯记录。不要执行不明模型仓库的任意脚本或远程代码来“试试看”。

### 15.2 Hugging Face 上的“模型”也不是同一种插件

1. 平台上可能有检测模型、识别模型、TrOCR 类图像文字识别模型、Donut 类文档理解模型及 VLM。输入、输出、依赖、字典和算力要求各不相同。
2. TrOCR 类模型常处理文字图块识别，不应未经适配就当完整整页检测流水线；Donut 类模型关注图像到结构化输出；VLM 可做更广泛问答，但可靠转写仍需测试。以具体模型卡为准。
3. 模型仓库存在不代表 RapidOCR 支持，也不代表有 ONNX、CPU 可用或可商业使用。先查任务、格式、运行示例和支持矩阵，再考虑适配。
4. 本轮没有联网查询当前三个 ONNX 在 Hugging Face 是否有镜像，不提供虚构地址，也不把平台搜索结果当当前模型官方来源。

## 16. 当前项目事实与资源交付

### 16.1 当前已知状态

1. 当前是本地 Demo，Python 3.12（已有记录为 3.12.16）、RapidOCR 3.10.0、onnxruntime 1.31.1，使用 CPU；本轮只做文档及资源元信息检查，没有重新执行环境、模型推理或精度测试。
2. 已有历史记录表明本地真实图片 OCR 跑通，且默认禁止下载时复跑成功；这证明候选链路可运行，不证明真实数字、字段、多组版面或生产接口已验收。
3. 已实现最小字段规则并有历史合成用例检查。最近字段边界修复后的真实结果重解析被权限系统阻止，本轮未尝试绕过；不能说真实字段修复回归已通过，也不能用 `status: ok` 代替目视对照原图。
4. 未进行训练或微调；HTTP、Java 接口、图片 URL 服务和其他字段尚未实现。生产选型、指标和接口仍待确认。
5. 本轮未读取真实图片或 OCR JSON，没有安装/同步依赖、联网下载或修改源码。运行方法与输出边界见 [README](../../README.md)。

3. 当前配置的模型发布渠道为 `https://www.modelscope.cn/models/RapidAI/RapidOCR`；本轮未联网确认页面、远端文件或完整训练/转换链。PP 系命名及适配关系不等于逐个核实了训练方、训练数据与许可证。
4. 三个模型来自不同任务/代际不必然是错误，但这是当前适配配置的组合，不能据此泛化为任意版本可混搭。

### 16.3 模型是运行资源，不提交 Git 也要可管理

1. `models/`、`test_file/`、`.ocr-output/` 按现有规则不进入 Git；前者是模型资源，后两者可能含敏感数据，不能一起当普通测试素材分享。
2. `uv.lock` 锁定 Python 依赖解析，不锁远端模型、字典和配置内容。相同依赖版本不保证取得相同模型。
3. 正式交付应另有受控制品清单：模型与字典名称、版本、来源、hash、许可证、输入/解码配置、转换工具版本、评估与审批记录。这些是应补齐要求，不因本文列了 hash 就认为已全部完成。
4. 离线部署应在受控构建/交付阶段准备资源、校验并打包；请求过程中不下载。缺模型时启动失败或按明确策略报错，不悄悄联网兜底。
5. 保留已验收旧模型、字典和配置用于回滚。更换模型、runtime、前处理或字段规则，都应触发对应范围回归。
6. 日志只保留必要标识、状态、耗时与版本；完整结果需访问控制和清理策略。规范见 [Python 开发规范](../PYTHON_DEVELOPMENT_STANDARDS.md)，不能以本文替代安全实现。
