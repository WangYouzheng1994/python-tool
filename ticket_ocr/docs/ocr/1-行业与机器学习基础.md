## 1. 行业全景与概念层级

### 1.1 不要把不同层的概念排成竞争产品

| 层次 | 回答的问题 | 例子 |
| --- | --- | --- |
| 领域与目标 | 希望机器解决什么智能问题 | AI、计算机视觉 CV、自然语言处理 NLP |
| 技术方法 | 通过什么机制解决 | 规则系统、传统机器学习、深度学习 |
| 具体任务 | 输入输出是什么 | 分类、检测、OCR、翻译、信息抽取 |
| 网络与算法 | 用什么计算结构和学习目标 | CNN、RNN、Transformer、CTC、检测算法 |
| 训练开发框架 | 用什么开发和训练 | PyTorch、PaddlePaddle、TensorFlow |
| 任务工具体系 | 如何组合数据、算法与工具 | PaddleOCR |
| 学习成果与制品 | 实际交付什么 | 预训练权重、checkpoint、ONNX 模型、字典 |
| 推理运行时与流水线 | 如何运行并还原结果 | ONNX Runtime、RapidOCR |
| 业务应用 | 如何满足业务契约 | 票据字段解析、校验、Java 服务接口 |

1. AI 是较大的领域；机器学习 ML 是其中通过数据学习规律的一类方法；深度学习 DL 是使用多层神经网络的机器学习方法。不是所有 AI 都是机器学习，也不是所有机器学习都是深度学习。
2. OCR 是“从图像识别文字”的任务，不是与深度学习平级的方法，也不是某一个库的专有能力。可以用不同方法和工具实现 OCR。
3. CV 处理图像、视频等视觉信息；NLP 处理语言；多模态把图像、文本等信息结合起来。OCR 连接视觉与文字，但传统专用 OCR 不因此就等于通用视觉语言大模型。
4. 分类回答“属于哪一类”；检测回答“在哪里、是什么”；识别转写回答“写了什么”；文档理解进一步回答“字段、表格、关系是什么”。这些任务可以组合，但验收指标不同。

### 1.2 从规则到现代深度学习

1. **规则与模板阶段**：阈值二值化、连通域、投影分割、模板匹配及人工规则，在字体和采集条件受控时有价值，换字体、光照或版式容易失效。
2. **传统机器学习阶段**：人工设计特征，再训练 SVM、树模型等分类器；模型也会从数据学习，不是纯手写规则，但特征表达更多依赖人工设计。
3. **现代深度学习阶段**：网络从数据学习层次化特征，用卷积、序列模型、注意力等处理复杂视觉和文字。仍依赖预处理、数据质量、解码和工程规则，不是“无需任何规则”。
4. 这不是旧方法被彻底消灭的时间表。实际工业系统常把深度模型、图像处理和确定性业务规则组合使用；小数据结构化任务也不一定需要大模型。
5. 行业能力来自一条链：芯片和驱动、数值计算库、训练框架、数据和标注、算法和训练、模型仓库、推理部署、应用服务。某公司提供其中几层，不代表其他层都由其原创或独占。

## 2. 图片、张量、特征与权重

### 2.1 图片如何进入神经网络

1. JPEG、PNG 是文件编码；解码后得到像素数组。RGB 通常每个像素有三个通道，像素原始值可以是 0～255 的整数。透明通道、EXIF 方向、颜色空间必须先明确处理。
2. 网络接收的是**张量 tensor**，即带形状和数据类型的多维数值数组。图像输入常见布局是 `NCHW` 或 `NHWC`：批量数、通道、高、宽；布局不是随意可换的。
3. 预处理可能包括缩放、补边、通道重排、转换浮点数、减均值和除标准差。例如除以 255 是数值缩放，不是让网络自行“认识图片”；必须与训练时约定匹配。
4. 文本也要编码：字符或 token 映射为 ID，可能再查 embedding 得到向量。OCR 解码字典负责把输出类别映射回字符，不等于模型里藏着一份完整句子词典。

纯文本流程：

```text
图片文件 → 解码像素 → 方向/通道/尺寸处理 → 张量 → 网络逐层计算
→ 输出分数或序列 → 解码 → 文字及位置 → 业务字段
```

### 2.2 输入变化的是激活，不是正常推理时的权重

| 对象 | 是什么 | 正常推理中是否随图片变化 |
| --- | --- | --- |
| 输入张量 | 当前图片的数值表示 | 是 |
| 权重和偏置 | 训练学到、参与运算的参数 | 通常不更新 |
| 特征与激活 | 各层对当前输入计算出的中间结果 | 是 |
| 输出 logits/分数 | 当前输入各类别或位置的预测值 | 是 |
| 解码文字 | 根据输出及字典、规则得到的字符串 | 是 |

1. 一层的简化表达是 `h = activation(Wx + b)`。`x` 是输入，`W`、`b` 是参数，`h` 是当前计算结果；真实网络还有卷积、注意力、归一化等操作。
2. 权重不是“识别这张图片时临时生成的数值”，特征也不是权重。相同权重处理不同图片，本来就会产生不同激活和输出。
3. 所谓特征，可以是边缘、纹理、笔画或更抽象的表示，但不能保证每个神经元都可直接解释成人类命名的规则。
4. **量化 quantization**特指用较低精度表示权重或激活等，例如 FP32 转为 INT8，可能涉及 scale、zero point、校准或量化感知训练。把图片变成数字是编码/张量化，不应笼统叫模型量化。
5. FP16/BF16 等低精度、INT8 量化各有数值与硬件条件；模型小了不必然更快，也不保证无精度损失，必须在目标运行时验证。
