# OCR 技术手册：从 AI 行业、模型训练到推理与票据工程

本文面向熟悉 Java 后端、初次系统接触机器学习的开发者，把行业分层、训练原理、数据集、训练框架、OCR 体系、模型制品、推理框架和工程改进串成一份自包含手册。先分清“任务、方法、工具、文件、运行时、业务”六种东西，再讨论选型。

本文是知识整理，不构成生产选型。当前状态以 [README](../README.md)、[需求](requirements.md)和[决策记录](../.agents/memory/decisions.md)为准；实际验证与限制见[交接](../.agents/memory/handoff.md)。本文不记录真实票据内容。外部参考未在本轮联网核验，不能把概念示例当成当前版本兼容承诺。
